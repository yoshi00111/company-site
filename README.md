# スカイライン・テクノロジーズ 企業サイト

業務システムとクラウドサービスを設計から運用まで手がけるソフトウェア開発会社「スカイライン・テクノロジーズ」のコーポレートサイトです。
`index.html` 1 ファイルで構成された静的サイトで、ビルドやサーバーは不要です。

## サイトの概要

建築の立面図をモチーフにしたデザインで、ヒーローの街並みから各セクションが「階」として積み上がる構成になっています。

| セクション | 内容 |
| --- | --- |
| お知らせ | 最新のニュース |
| ヒーロー | キャッチコピー「土台から設計し、高く積み上げる。」とスカイラインのイラスト |
| 事業内容 | 自社SaaSの企画・開発／Web・モバイルアプリ開発／基幹システムの刷新／クラウド基盤の構築と運用 |
| 導入事例 | 配送ルート計画システム、クリニック向け予約アプリ、工場設備の稼働監視基盤 |
| 開発の進め方 | 地盤調査 → 基本設計 → 施工 → 竣工・保守 の 4 ステップ |
| 会社概要 | 会社情報 |
| 採用 | 採用情報 |
| お問い合わせ | 入力チェック付きのフォーム（デモのため実際には送信されません） |

### 主な特徴

- スマートフォンからデスクトップまで対応するレスポンシブレイアウト
- OS の設定に合わせたライト／ダークモード
- Google Fonts（Archivo、IBM Plex Mono、Zen Kaku Gothic New）を使用

## ブラウザで index.html を開く手順

### 方法 1: ファイルを直接開く（いちばん簡単）

1. エクスプローラー（Mac は Finder）でこのフォルダを開きます。
2. `index.html` をダブルクリックします。
   - 既定のブラウザ以外で開きたい場合は、右クリック →「プログラムから開く」でブラウザを選ぶか、ブラウザのウィンドウに `index.html` をドラッグ＆ドロップします。

### 方法 2: コマンドラインから開く

リポジトリのフォルダで次のコマンドを実行します。

```sh
# Windows（PowerShell / コマンドプロンプト）
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### 方法 3: ローカルサーバーで開く（任意）

`http://` の URL で確認したい場合は、簡易サーバーを立ち上げます。

```sh
# Python がある場合
python -m http.server 8000

# Node.js がある場合
npx serve .
```

起動後、ブラウザで `http://localhost:8000`（`npx serve` の場合は表示された URL）を開きます。

> **補足:** Web フォントは Google Fonts から読み込むため、インターネットに接続していない環境では代替フォントで表示されます。
